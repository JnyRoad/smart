## 修复与独立评审

本轮先补失败测试，再修复领域和界面问题。独立评审确认以下修正：

- 成功通行后清空短时核验，每次进出重新扫描；未确认写入才保留人工重试键，不能把旧成功响应用于下一次通行。
- 身份、岗位、核验切换后，迟到的成功/错误响应不能恢复旧上下文；成功写入使先前列表请求失效，旧快照不能覆盖新事件。
- 物品申请成功但后续列表读取失败时保留已创建单号；过期会话和无权限操作不能表现为成功。
- Android 共用样式改用原生支持的类选择器与 flex，Web 专有焦点样式受条件编译保护。构建脚本同时检查退出码与编译诊断，防止编译器报告 CSS 错误却退出 0 被误判成功。
- 权限守卫立即返回拒绝，导航推迟到 `nextTick`，避免挂载途中同步切页留下失效缓存；会话代次约束旧跳转。新增回归先失败再通过，完整浏览器流程确认异常链接不再空白。
- HBuilderX Web 输入同步存在 100ms 节流。扫码使用 confirm/blur 的即时值，并在完整接收后重建输入，避免连续扫码被旧回显覆盖；独立复核通过。

## 可复现命令

HBuilderX 应打开本任务工程，用户最初创建的主 checkout 工程保持不变：

```bash
cd <worktree>/smart-app
npm test
npm run build:web
npm run build:weixin
npm run build:alipay
npm run build:android
npm run preview
```

需要复现隔离本机 API 闭环时，先按 [Docker 演示说明](../../docker/app-demo/README.md) 启动环境，再在 `smart-app/` 运行：

```bash
npm run demo:enable
npm run test:demo-api
npm run demo:disable
```

`build:android` 不生成签名安装包。另开终端执行浏览器检查：

```bash
npm install --no-save playwright
npx playwright install chromium
npm run test:e2e
node tests/scan-entry.e2e.mjs
node tests/ui-audit.mjs
```

也可设置 `PLAYWRIGHT_MODULE_PATH` 指向仓库外的 Playwright 模块目录。本轮使用现有外部运行时，没有新增项目依赖。受限沙箱不允许 Chromium 启动时，在已获准的本机环境运行同一演示检查。

## 工具链限制

- 原生编译使用 `/Applications/HBuilderX.app/Contents/HBuilderX/plugins/node/node`（Node 22）。Node 18 在 Vapor 的 `.jsc` 模块上会出现 `cachedDataRejected`，不用于本工程编译。
- HBuilderX Qt CLI 在受限环境曾报告 `Incompatible processor. This Qt build requires neon`；构建脚本直接调用安装目录内的 Vite 入口。
- Node 测试要求 24 以上，`scripts/uts-loader.mjs` 仅为 `.uts` 注册类型擦除钩子。HBuilderX 能从 `.uvue lang="uts"` 导入普通 `.ts`，但新增 `.ts` 测试模块前仍需扩展该测试加载器。
- Web 与支付宝的相机扫码暂未适配，会明确提示切换输入模式。App/微信相机调用仍需真机核验。
