# Feature Specification: 项目规则与开发资料持久化

**Feature Branch**: `chore/project-agent-workflow`
**Created**: 2026-09-04
**Status**: Approved
**Input**: 旅途已确认：按评估方案实施规则路由、独立 worktree 开发、已有规格复用和开发资料入库。

## User Scenarios & Testing

### User Story 1 - 换工作区仍能取得开发资料 (Priority: P1)

旅途在新的工作区继续任务时，可以取得已提交的规格、设计和验收资料，无需重新生成。

**Independent Test**: 从提交生成干净检出，核对两组门锁文档共 21 个文件以及已有规格均存在；本机指针和缓存仍不入库。

**Acceptance Scenarios**:
1. 已有本地门锁资料，纳入版本管理后，新检出可以读取完整且内容相同的 21 个文件。
2. 已有功能规格但没有本地指针时，明确绑定原规格目录，继续任务，不创建重复功能。

### User Story 2 - 每个开发任务有独立工作区 (Priority: P1)

Agent 在首次修改文件前确认本任务的工作区和分支，保护 main 和其他任务的改动。

**Independent Test**: 对照 main、共享目录功能分支、已有任务 worktree、detached worktree、旧任务 worktree 五种状态，规则给出明确且互不冲突的动作。

**Acceptance Scenarios**:
1. 在 main 或共享主目录开发时，先建立独立工作区和任务分支，再写规格与代码。
2. 已有本任务 worktree 和分支时直接复用；detached 时从当前 HEAD 建分支，不重新创建 worktree。
3. 创建隔离失败时停止依赖写入，不退回 main 开发，不自动处理其他任务的脏文件。

### User Story 3 - 按需加载一致的规则 (Priority: P2)

Agent 从根规则获得必须遵守的边界，再按任务读取具体流程，不依赖某台机器的个人规则。

**Independent Test**: 根路由链接全部可解析；项目工作流在规格分析后交给执行技能，不调用被禁止的实现入口。

**Acceptance Scenarios**:
1. 开发、规格续作与只读评估分别有明确加载范围。
2. 工作流和命令模板体现测试先行；低风险纯文档变更使用链接、内容和差异检查。

### Edge Cases

- 主目录中原有 `.superpowers/sdd/task-2-report.md` 删除不属于本任务，不恢复、不提交该删除。
- 目录被忽略不代表已有文件未跟踪；分别核对忽略、索引、HEAD 和远端。
- 同一分支被其他 worktree 占用时，不强制重复检出或自动切换他人目录。
- worktree 不隔离外部服务、数据库和端口；业务文档中的规划不视为当前实现。

## Requirements

### Functional Requirements

- **FR-001**: 持久规格、设计、计划和验收资料必须允许进入版本管理；本机状态继续精确忽略。
- **FR-002**: 开发首次写入前必须同时具备独立 worktree 和本任务非 main 分支。
- **FR-003**: 已有本任务工作区、分支和规格必须优先复用。
- **FR-004**: 根规则必须保留硬约束，并按任务路由到三个详细规则文件。
- **FR-005**: 项目工作流必须移除自动实现路径，并将分析通过的任务清单交给执行技能。
- **FR-006**: 对代码行为改动采用有意义的测试先行；文档与低风险配置改动使用适当检查。
- **FR-007**: 所有本次新增资料及规则通过功能分支提交到 origin，并创建 PR；不自动合并。

## Success Criteria

- **SC-001**: 两组门锁资料 21 个文件均能从提交取得，内容与原始资料逐文件一致。
- **SC-002**: 工作区决策的五类状态均有明确动作，不允许 main 或共享主目录开发。
- **SC-003**: 规则路由没有断链，持久资料不再命中整体忽略，本机指针仍被忽略。
- **SC-004**: 工作流相关检查通过；已有规格可在没有本地指针的干净检出中只读解析。

## Assumptions

- 采用用户上一轮批准的轻量拆分，不引入新服务或通用规则引擎。
- 本轮不修改业务代码、部署环境、全局个人规则或历史规格。
- 门锁资料保持原文；涉及外部仓库的引用仅作为已有资料来源，不宣称可独立复现外部系统。
