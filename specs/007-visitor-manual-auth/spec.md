# 功能规格：访客手动下发权限（蓝图 5.2）

**功能分支**：`feat/visitor-manual-auth`

**创建日期**：2026-09-05

**状态**：ISC 公共人员能力已实现并通过本地验证；未合并、未部署

**输入**：依据 `docs/yuhui-prototype/yuhui-blueprint.html#item-5-2` 实现访客手动下发权限。

## 用户场景与测试

### 用户故事 1：单选申请并下发权限（P1）

管理员在入厂申请记录单选一张申请，打开「通关权限」，选择该申请中的一名人员及目标 ISC 权限组，确认后提交下发任务。长期供应商使用相同入口。

**独立测试**：有权限的管理员对有效申请选择人员和公共 ISC 权限组，得到成功提交提示及批次号；任务包含该人员、申请单和不可修改的截止时间。

**验收场景**：
1. 未选择卡片时按钮不可用；选择另一张后只保留最新选择，点击卡片详情或作废按钮不触发下发。
2. 弹窗使用双栏权限选择，布局、橙色主按钮、字体和间距对齐 docs Web 原型与现有员工通关权限弹窗；申请单有效期置于双栏下方、操作按钮上方，起止时间只读；切换人员时清空已选权限组。
3. 只下发明确选择的本单人员；权限组映射到同一设备时只创建一份任务。
4. 请求成功提示「下发任务已提交」，不声称设备已生效；失败保留选择并展示原因，重复点击提交不产生并发请求。

### 用户故事 2：拒绝非法或未满足前置条件的授权（P1）

管理员只能在本人可访问的园区，为有效且已通过审批的申请分配本园区、与对象类型匹配的权限。涉密权限必须具备可核验的考试通过依据。

**独立测试**：对越权园区、无效申请、跨申请对象、错误类型或涉密权限提交，均拒绝且不创建任务。

**验收场景**：
1. 未认证、无操作权限、跨园区、对象不属于申请、权限组不存在或跨园区时拒绝。
2. 待审批、已拒绝、已作废、已离开、超时或时间倒置申请不得下发；正常已通过/已到达且未过期申请可下发。
3. 无照片（照片 ID 为空或仅空白）的人员不列入可选对象；提交时仍重新校验照片，缺失则明确失败。权限组无可用匹配设备或包含非 ISC 设备时明确失败；车辆下发当前底层不支持，入口说明且不允许提交。
4. 与作废并发时不得在作废完成后留下新的有效下发任务；任务保存任一步失败整体回滚。
5. 当前基线尚无 5.1 考试通过查询能力，涉密下发明确拒绝并提示依赖缺失；禁止以日志代替校验。本次不扩展为完整考试管理功能。

## 需求

- **FR-001**：申请卡片支持单选，工具条提供受操作权限控制的「通关权限」入口，翻页/重新查询清除选择。
- **FR-002**：弹窗复用员工双栏选择交互和系统现有视觉风格，只展示本单对象和同园区匹配权限组；对象与权限均必选；有效期位于内容区最下方。
- **FR-003**：每次只提交一名人员，不隐式批量授权所有随行人员。
- **FR-004**：有效期由申请单确定，生效时间按现有提前量，截止时间取申请单原值；忽略或拒绝客户端伪造的日期。
- **FR-005**：新接口必须经过认证、操作权限、园区、申请状态、对象归属、权限组与设备匹配校验。
- **FR-006**：新 ISC 任务记录申请单、新批次及人员身份；人员卡号为随行记录 ID；设备去重。
- **FR-007**：操作与作废串行，所有任务在同一事务内保存；不新增本地延迟删除任务。
- **FR-008**：涉密权限在缺少考试通过依据时拒绝，普通权限不依赖考试管理。
- **FR-009**：成功表示任务已提交；失败如实展示且可修正重试；提交期间禁重复点击。
- **FR-010**：保留详情返回、查询条件、重新下发及单条作废现有行为；员工有效期功能保持兼容。

## 关键实体

- 申请单：审批状态、园区、来访有效期及关联人员/车辆。
- 下发对象：本申请的一名人员；车辆仅作为拒绝范围。
- 权限组：所属园区、对象类型、公共/涉密性质及关联设备。
- 下发批次：一次操作所生成的设备任务集合，保留申请与对象追溯信息。

## 成功标准

- **SC-001**：管理员在同一弹窗完成对象和多组权限选择并得到明确提交结果。
- **SC-002**：自动化测试证明任务身份、截止时间和批次正确，非法请求不创建任务。
- **SC-003**：自动化测试覆盖单选、人员切换、不可编辑有效期、请求失败及重复点击行为。
- **SC-004**：真实 Oracle、ISC 设备到期失效及长期供应商现场流程单独验收，不以本地 Mock 代替。

## 范围与假设

- 本次是 5.2，5.1 尚未实现时采用拒绝涉密下发的保守行为；5.1 后续提供真实证件号考试查询后再接通涉密能力。
- 新功能使用独立管理路由，避免历史访客 H5 放行路径；操作权限上线授予由现有权限管理流程处理。
- 不新增数据库表/字段，不执行真实数据库写入、设备操作或部署；提交、推送和 PR 按会话授权执行。

- 底层能力核验补充：`SmtIscDeviceTaskServiceImpl.saveTask` 当前拒绝车辆；标准 `SmtDeviceTask` 无 applyId/batchId。首版仅开放可完整保存追溯字段的 ISC 人员权限；车辆及非 ISC 设备明确拒绝，待对应底层能力具备后再扩展，不按成功处理。
