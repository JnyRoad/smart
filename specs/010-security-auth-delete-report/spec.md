# 功能规格：保密区权限自动删除记录报表

**任务分支**：`feat/security-auth-delete-report`

**创建日期**：2026-09-05

**状态**：业务源码、迁移和升级资料已完成，本地业务验证通过；未部署

**输入**：核对 docs 蓝图并评估、实现自动删除权限的独立历史记录和执行状态报表。

## 用户场景与测试

### US1 查询自动删权历史（P1）

管理员在保密区功能组进入“权限自动删除记录”，查看何时判定、涉及哪些人员及权限组、为什么处理及执行结果。

**独立验收**：自动任务处理白名单、未到期、无设备、员工缺失、正式删权、异常各一条，均有可查询记录；人员或权限组后续修改、删除后，原记录的名称、部门等快照保持不变。

1. 按执行日期、园区、工号、姓名、部门、权限组、结果组合查询，分页结果与筛选一致。
2. 正式删权产生多个设备任务时，记录关联全部任务；执行中、失败、全部成功与任务记录缺失有明确区分。
3. 单条处理失败回滚该条业务操作并保存失败记录，后续人员继续处理；审计记录无法保存时任务明确失败。

### US2 导出和任务下钻（P1）

管理员导出当前筛选范围的记录，打开某一记录查看关联设备任务、状态、时间和失败说明。

**独立验收**：导出包含当前条件匹配且有权限查看的全部记录，超出 10000 条明确要求缩小范围，不静默截断；直接请求其他园区的记录详情也不得读取。

### US3 演练名单核对（P2）

管理员启用园区演练模式后，任务正常判定并记录“演练命中”，不删除权限关联、不生成设备任务。

**独立验收**：演练、白名单与天数阈值分支分别验证；存量配置和未传演练字段的既有调用保持原模式。

### 边界情况

- 无园区数据范围时默认拒绝读取任何记录；客户端不能扩大令牌数据范围。
- 日期反向、页码/页大小非法、结果代码非法时明确报错；分页最大 100 条。
- 同一人员同一权限多次判定分别留痕；并发扫描不得重复删除已经不存在的权限关联。
- 设备任务丢失或被清理时显示“任务状态未知”，不将未知当成功。
- 白名单在查进出记录前命中时，最后进出时间允许为空，不伪造时间。

## 功能要求

- **FR-001**：每条参与判定的权限产生独立审计记录，保存执行时间、园区、人员、部门、权限组、最后进出时间、触发原因、结果、说明。
- **FR-002**：正式删权审计关联全部设备任务，区分待执行/执行中、成功、失败、未知；成功仅表达任务记录成功，不宣称所有设备已完成物理确认。
- **FR-003**：支持服务端组合筛选、稳定分页排序和刷新，姓名、工号、部门、权限组按名称模糊匹配。
- **FR-004**：分页、导出和任务详情统一校验登录权限与园区数据范围。
- **FR-005**：导出遵循相同筛选和状态口径，限制 10000 条，记录完整且防止表格公式注入。
- **FR-006**：逐条事务隔离；权限变更、任务生成及成功审计原子提交；失败审计在回滚后独立保存。
- **FR-007**：园区配置支持演练模式，并保存演练判定；不扩大既有自动任务的启动范围。
- **FR-008**：管理端保密区提供报表菜单、清晰状态说明和任务详情；历史资料不足不得伪造回填。

## 关键实体

- 自动删除判定记录：一次人员权限判定的不可变身份与原因快照，关联实际生成的任务。
- 关联设备任务：一条判定对应零到多个任务，任务当前状态与历史快照分开展示。
- 园区自动删除配置：沿用现有阈值、假期过滤与白名单，仅增加演练标识。

## 成功标准

- **SC-001**：上述所有判定分支及异常场景均可查到记录，正式删权记录能查看全部关联任务。
- **SC-002**：分页、导出、详情的跨园区测试全部拒绝越权访问。
- **SC-003**：目标环境按园区查询首页在 3 秒内返回；以现场数据与执行计划验收，本地单测不构成性能证明。
- **SC-004**：演练命中不触碰真实权限或设备任务，失败处理不回滚其他人员已完成结果。
