# Data Model: 入厂申请随行人员搜索

本功能不改变数据模型。

| Entity | Existing relationship | Search role | Change |
|--------|-----------------------|-------------|--------|
| 入厂申请单 | 结果主记录 | 返回给列表的主记录，`VISITOR_NAME` 与 `CERT_NO` 可作为搜索依据 | 无 |
| 随行人员 | `VISITOR_ID` 关联主申请单 | 姓名和证件号搜索依据；只通过存在性条件筛选 | 无 |

孤儿随行人员没有可关联的主申请单，因而不能作为搜索结果。它们不在本功能中清理。
