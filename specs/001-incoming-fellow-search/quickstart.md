# Quickstart: 入厂申请随行人员搜索验证

1. 在可控测试数据中准备一张无多车的主申请单：主访客姓名不包含“王小雨”，其证件号为 A；
   至少两位随行人员姓名均为“王小雨”，另有一位姓名不匹配的随行人员，匹配随行人员证件号为 B。
2. 在入厂申请记录输入“王小雨”，确认返回该主申请单；把返回记录按申请单 <code>ID</code> 分组，
   该申请单计数应为 1，即两位匹配随行人员不增加结果行。
3. 清空姓名，分别输入主访客证件号 A 和随行人员证件号 B，均确认返回同一主申请单且分组计数为 1。
4. 用主申请人姓名、空条件和园区/状态组合条件复测既有行为；另在有多车的申请单上记录无随行条件
   的基线计数，再确认增加匹配随行人员后该计数不变。
5. 运行平台 Maven Mapper 动态 SQL 契约测试，并在管理端页面复核筛选标签保持为“访客姓名”“访客证件号”。
   该测试只验证 SQL 生成和参数绑定，不能替代上述真实页面的结果基数验收。
   若需要生产计划复核，使用具备只读 `DBMS_XPLAN.DISPLAY_CURSOR` 权限的账号；不要用本功能
   账户写入 `PLAN_TABLE`。
