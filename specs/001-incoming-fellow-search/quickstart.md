# Quickstart: 入厂申请随行人员搜索验证

1. 在可控测试数据中准备一张主申请单及三位随行人员，其中至少一人的姓名和证件号不与
   主申请人相同。
2. 在入厂申请记录输入该随行人员姓名，确认返回主申请单且只一条。
3. 清空姓名，输入该随行人员证件号，确认返回同一主申请单且只一条。
4. 用主申请人姓名、空条件和园区/状态组合条件复测既有行为。
5. 运行平台 Maven Mapper 动态 SQL 契约测试，并在管理端页面复核筛选标签为“访客/随行姓名”。
   若需要生产计划复核，使用具备只读 `DBMS_XPLAN.DISPLAY_CURSOR` 权限的账号；不要用本功能
   账户写入 `PLAN_TABLE`。
