# 数据模型：手动下发权限有效期

## 权限下发请求

| 字段 | 含义 | 规则 |
|---|---|---|
| `startTime` | 生效时间 | 可省略；省略时为服务端当天 00:00:00 |
| `endTime` | 截止时间 | 可省略；省略时为 2030-12-31 23:59:59 |
| `ids` / `badges` | 待授权员工 | 沿用各入口既有校验 |
| `deviceAuthIds` / `authId` | 目标权限组 | 沿用各入口既有校验 |

**不变量**：归一化后 `startTime <= endTime`；违反时请求必须整体失败并且零写入。

## 员工—权限组关联

| 字段 | 含义 | 生命周期 |
|---|---|---|
| `staffId` | 员工标识 | 既有关系字段 |
| `authId` | 权限组标识 | 既有关系字段 |
| `startTime` | 本次授权开始时间 | 用于展示，不触发删除 |
| `endTime` | 本次授权截止时间 | 用于展示，不触发删除 |

追加模式下已有关系不更新有效期；覆盖模式创建的关系使用本次请求窗口。

同一员工的多个关联映射到同一设备时，设备任务读取最后一次授权关系的日期。按 `CREATE_TIME` 判定先后；时间相同时，已持久化记录取更大的关联主键，本次待保存关系优先于历史关系。

## ISC 下发任务

| 字段 | 含义 |
|---|---|
| `START_TIME` | 下发到设备端权限配置的开始时间（秒） |
| `OVER_TIME` | 下发到设备端权限配置的截止时间（秒） |
| `action` | 本功能只创建下发动作，不创建延迟删除动作 |
