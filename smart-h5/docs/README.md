# smart-h5/docs

`smart-h5/docs/` 保存微信 H5 的评估、架构、原型、设计规格和实施计划。

## 目录结构

```text
smart-h5/docs/
├── README.md
├── mockups/          # 早期登录等页面 mockup 和评审材料
├── prototype/        # 页面原型、HTML mockup、设计指南和功能规格
└── superpowers/      # 开发计划和设计规格
```

## 维护规则

- 页面/流程变更前先更新对应规格或计划。
- 原型 HTML 用于功能对版，不等同于生产代码。
- 与后端接口有关的结论要标明来源，不能只写视觉预期。
