# smart-file

`smart-file` 是历史文件服务模块。当前根发布清单未包含它，默认不作为新功能入口。

## 目录结构

```text
smart-file/
├── README.md
├── pom.xml
├── smart-file-api/   # 历史文件服务 API / Feign 契约
└── smart-file-biz/   # 历史文件服务实现目录；当前基线只看到构建产物目录
```

## 模块边界

- 新功能不要默认依赖本模块。
- 文件上传、图片存储、业务附件应优先按当前调用链确认实际归属，再落到对应业务模块或公共工具。
- 若要恢复此模块，先补齐源码、打包方式、发布清单和回归测试。

## 构建说明

当前发布脚本没有收集 `smart-file` 产物。不要把普通 library jar 手工加入发布包。
