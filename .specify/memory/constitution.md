# Smart Constitution

## 权威来源

本宪法是 Spec Kit 的项目规则索引。各主题只在下列来源维护正文：

| 主题 | 来源 |
| --- | --- |
| 开发工作区、任务分支与 PR 交付 | [Git 与 worktree](../../docs/agent-rules/git-worktree.md) |
| 业务权限、Oracle、中文说明和具体验收 | [开发规则](../../docs/agent-rules/development.md) |
| 规格绑定、持久资料、命令与执行交接 | [规格工作流](../../docs/agent-rules/spec-workflow.md) |
| 技术栈、模块范围与运行命令 | [项目 README](../../README.md)及对应模块 README |

规格描述用户确认的目标和约束；实现状态依据当前源码、配置及运行证据。具体任务的适用范围与例外记录在该任务规格中，不将平台 Java/Oracle 约束套用于 Next.js 或 App 客户端。
