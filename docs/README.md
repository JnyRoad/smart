# docs

`docs/` 保存项目级资料、跨子项目说明和不属于单一子项目的文档。

当前目录不是 `smart/` 后端的开发文档目录；后端基础平台文档在 [../smart/docs/](../smart/docs/)，H5 原型和实施文档在 [../smart-h5/docs/](../smart-h5/docs/)。

## 目录结构

```text
docs/
├── README.md
└── 管理端页面功能清单文档        # 管理端页面、功能和对版参考
```

## 维护规则

- 项目级文档放这里；某个子项目独占的设计、接口、原型、ADR 放回对应子项目自己的 `docs/`。
- 清单类文档要标明来源和适用范围，避免被误读为当前实现承诺。
- 涉及生产配置、账号、密钥、真实客户数据的材料不要提交。
