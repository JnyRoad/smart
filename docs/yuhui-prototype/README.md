# 裕慧家园开发蓝图与交互原型（2026-08）

本目录是「裕慧家园新增功能（40 项）」的完整演示套件，**全部离线可用**：直接双击 `index.html` 即可在浏览器打开并互相跳转，无需任何服务器或网络。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 主页入口（三张卡片跳转） |
| `yuhui-blueprint.html` | 开发蓝图：架构 / 核心流程图 / 40 项需求×原型对照表 / 开发批次 / 确认清单（左侧导航翻章，支持打印） |
| `yuhui-app-proto.html` | App 端完整交互原型（Mock）：左侧演示控制台切换 4 个账号，把一张保密放行单从申请走到归档；演示数据刷新即复位 |
| `mermaid.min.js` | 流程图离线渲染库（蓝图本地打开时使用；请与蓝图放在同一目录，勿删除） |
| `yuhui-web-proto.html` | Web 管理后台原型：复刻现有 smart-ui 界面风格，40 项改动全部可点演示；橙「新」= 新增页面，蓝「改」= 现有页面改造 |

## 演示建议

1. 打开蓝图，先看第 3 章核心流程图；
2. 按第 4 章「演示剧本」打开 App 原型走完一单（约 5 分钟）；
3. Web 原型从首页卡片逐个进：重点演示「权限策略→人员明细→清空权限」（5.8 删除回执全过程）与「入厂申请记录」勾选卡片后右上角作废/通关权限；
4. 对照第 5 章「40 项需求×原型对照表」逐项确认。

与《裕慧家园系统新增功能需求分析.md》《裕慧家园系统新增功能调研与实施方案.md》(v1.5) 一致；UI 按最终实现阶段设计（申请与主管审批在 App 内、园区审批引擎、不走 OA；第一阶段申请暂留 OA/现有系统）。
