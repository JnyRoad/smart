# smart

本仓库用于管理智慧园区相关项目代码。当前包含 H5 应用，后续可按模块增加前端、后端和其他业务项目。

## 目录

```text
smart/
  smart-h5/     智慧园区 H5 应用
```

## 当前项目

- `smart-h5/`：基于 Next.js 的智慧园区 H5 应用。

后续新增模块时，按独立子目录放在仓库根目录下，并在本文件补充说明。

## Git 规则

根目录 `.gitignore` 统一忽略依赖、构建产物、测试报告、日志、环境变量文件和本地编辑器配置。提交前先执行：

```bash
git status --short
```

确认没有 `node_modules/`、`.next/`、`coverage/`、`.env*` 等本地文件进入暂存区。
