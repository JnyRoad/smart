# WEB-L-006 授权下发结果

## 目标与落点

旧页面为 views/platform/key/auth-result/index.vue，建议目标为 smart-ui/src/views/platform/key/auth-result/。这是权限页面提交后的结果查询入口，不把它合并成只显示“提交成功”的轻提示。

## 操作基线

| 项目 | 第一版要求 |
|---|---|
| 筛选 | 工号、姓名、手机号、授权设备。 |
| 表格 | 工号、姓名、手机号、钥匙类型、授权设备、状态、描述、创建时间。 |
| 行为 | 查询与分页；保留返回权限管理或跳转关联授权的清晰路径。 |
| 状态 | 至少区分已创建、待投递、已送达待确认、设备确认、失败、需人工核验；旧状态名称与新状态映射必须记录。 |

旧包可见 GET /device/task/page。新系统应按命令、目标和回执聚合返回结果，不能以 Socket 写入或 HTTP 返回成功替代设备确认。

## 验收

覆盖无记录、分页、筛选、单条失败、批量部分失败、迟到回执和刷新。用户从 WEB-L-005 提交后能准确找到对应批次/目标，且不会因为刷新把失败或待确认错误地标为完成。
