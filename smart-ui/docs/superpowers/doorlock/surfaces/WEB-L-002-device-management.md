# WEB-L-002 设备管理

## 目标与落点

旧页面为 views/platform/facility/device/index.vue。建议目标为 smart-ui/src/views/platform/facility/device/，与 WEB-L-001 的“门锁浏览/详情”并列，不能因为已有宿舍绑定页就省略此设备管理入口。

## 查询与表格

| 区域 | 对版要求 |
|---|---|
| 筛选 | 园区、设备 ID、设备名称、宿舍级联位置、连接状态。 |
| 表格 | 设备 ID、名称、位置、连接状态、是否可用开关、备注。 |
| 批量选择 | 保留多选能力，未选择时不可执行批量修改管理员密码。 |

## 操作

| 操作 | 旧版行为基线 | 新版约束 |
|---|---|---|
| 编辑 | 修改设备信息与备注。 | 服务端校验园区、版本和状态；冲突必须可见。 |
| 解绑 | 显式确认后解除绑定。 | 先展示对有效授权、房间和待执行命令的影响，不能静默取消物理权限。 |
| 启停 | 表格中的可用开关。 | 状态变化必须有权限、原因、审计和设备侧后果说明。 |
| 修改管理员密码 | 输入 6 至 10 位数字并二次确认。 | 密码不得回显、写日志或写入前端持久化；仅显示受理/确认状态。 |
| 批量修改管理员密码 | 多选设备后提交。 | 服务端批处理、限流、结果逐设备可查询；浏览器不得循环调用。 |
| 修改全部管理员密码 | 一键全量入口。 | 只允许受限角色，在影响预览、二次确认和变更单/审计后提交。 |

## 历史接口证据

旧包包含 GET /device/page、PUT /device/info、GET /device/unbind/{id}、PUT /device/enable/{id}/{status}、PUT /device/manager/pwd/{deviceId}/{password}、PUT /device/manager/batch/pwd、GET /park/remote/dormitory。新页面以 smart-lock 接口替换，不沿用把密码放在 URL 的旧模式。

## 验收

至少覆盖：筛选和级联位置、无权限、无选中批量操作、解绑确认/取消、单台密码格式校验、批量部分失败和状态刷新。旧表格列、行操作排序、弹窗层次和禁用条件须以运行态证据对版。
