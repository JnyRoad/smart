# WEB-L-002 设备管理

## 目标与落点

旧页面为 views/platform/facility/device/index.vue。建议目标为 smart-ui/src/views/platform/facility/device/，与 WEB-L-001 的“门锁浏览/详情”并列，不能因为已有宿舍绑定页就省略此设备管理入口。

## 查询与表格

| 区域 | 对版要求 |
|---|---|
| 筛选 | 园区、设备 ID、设备名称、宿舍级联位置、连接状态。 |
| 表格 | 设备 ID、名称、位置、连接状态、是否可用开关（待核验；未确认前受控不可用）、备注。 |
| 批量选择 | 批量密码入口待核验；须待版本、账号角色、资源权限、API 和设备状态能力全部确认后开放，未选择时不可执行批量修改管理员密码。 |

## 操作（未核验项受控不可用）

| 操作 | 旧版行为基线 | 新版约束 |
|---|---|---|
| 编辑 | 运行态确认有编辑入口；修改设备信息与备注的字段仍须按证据对版。 | 服务端校验园区、版本和状态；冲突必须可见。 |
| 解绑 | 离线 bundle 可见，运行态未确认。 | 待版本、账号角色、资源权限、API 和设备状态能力全部确认后开放；此前受控不可用，并须展示对有效授权、房间和待执行命令的影响。 |
| 启停 | 离线 bundle 可见，运行态未确认。 | 待版本、账号角色、资源权限、API 和设备状态能力全部确认后开放；此前受控不可用，开放后状态变化必须有权限、原因、审计和设备侧后果说明。 |
| 修改管理员密码 | 离线 bundle 可见输入 6 至 10 位数字并二次确认，运行态未确认。 | 待版本、账号角色、资源权限、API 和设备状态能力全部确认后开放；此前受控不可用。开放后密码不得回显、写日志或写入前端持久化，仅显示受理/确认状态。 |
| 批量修改管理员密码 | 离线 bundle 可见多选设备后提交，运行态未确认。 | 待版本、账号角色、资源权限、API 和设备状态能力全部确认后开放；此前受控不可用。开放后由服务端批处理、限流，结果逐设备可查询，浏览器不得循环调用。 |
| 修改全部管理员密码 | 离线 bundle 可见一键全量入口，运行态未确认。 | 待版本、账号角色、资源权限、API 和设备状态能力全部确认后开放；此前受控不可用。开放后只允许受限角色，在影响预览、二次确认和变更单/审计后提交。 |

## 历史接口证据

旧包包含 GET /device/page、PUT /device/info、GET /device/unbind/{id}、PUT /device/enable/{id}/{status}、PUT /device/manager/pwd/{deviceId}/{password}、PUT /device/manager/batch/pwd、GET /park/remote/dormitory。新页面以 smart-lock 接口替换，不沿用把密码放在 URL 的旧模式。

## 验收

至少覆盖：筛选和级联位置、无权限、无选中批量操作、解绑确认/取消、单台密码格式校验、批量部分失败和状态刷新。当前未核验操作先验入口不可用；经版本、账号角色、资源权限、API 和设备状态能力确认并开放后，才验解绑及单台/批量/全量改密的完整操作流程。旧表格列、行操作排序、弹窗层次和禁用条件须以运行态证据对版。
